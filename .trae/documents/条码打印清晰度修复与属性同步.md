# 条码打印清晰度修复与属性同步

## 摘要

修复热敏打印机打印条码不清晰的问题，并将表格单元格中条码的 `barWidth`（条宽倍率）和 `fontSize`（文本字号）属性同步到独立条码元素中，使两类条码元素配置一致。

## 当前状态分析

### 问题一：热敏打印不清晰

**根因**：条码渲染参数硬编码，未充分利用用户配置的 `barWidth` 等参数。

1. **独立条码元素渲染管线**（`browser-code-renderer.ts`）：
   - `width: Math.max(1, (opts.barWidth ?? 2) / 2)` — `barWidth` 仅部分生效，默认值 2 导致 `width=1`，条码过细
   - `height: 30` — 硬编码，不随元素高度调整
   - `margin: 0` — 无静默区，热敏打印易被裁切
   - `fontSize: opts.fontSize ?? 10` — 默认字号偏小

2. **表格单元格条码**（`CellBarcode.vue`）：
   - `width: 1` — 硬编码，完全忽略 `barWidth`
   - `height: 28` — 硬编码
   - `margin: 0` — 无静默区
   - `fontSize: 9` — 硬编码

3. **对比其他设计软件**：专业条码软件通常为热敏打印设置 `barWidth >= 2`（对应 jsbarcode `width >= 2`），`margin >= 2`，确保条宽足够且不被裁切。

### 问题二：属性面板不一致

| 属性 | 独立条码元素（`CodeGroup.vue`） | 单元格条码（`TableCellGroup.vue`） |
|------|------|------|
| 码制 | ✅ 有 | ✅ 有 |
| 条宽倍率（`barWidth`） | ✅ 有（2-4，步进 0.5） | ❌ 缺失 |
| 显示文本 | ✅ 有 | ✅ 有 |
| 文本字号（`fontSize`） | ✅ 有（5-24pt） | ❌ 缺失 |
| 纠错级别（二维码） | ✅ 有 | ✅ 有 |
| 缩放模式 | ✅ 有 | ✅ 有 |
| 最大宽高 | ✅ 有 | ✅ 有 |

## 修改方案

### 1. 修复 `browser-code-renderer.ts` — 渲染管线条码参数

**文件**：`packages/print-core/src/browser/browser-code-renderer.ts`

**改动**：
- `width`：改为 `Math.max(2, (opts.barWidth ?? 4) / 2)`，默认 `barWidth=4` → `width=2`，热敏打印更清晰
- `height`：改为 `opts.barHeight ?? 40`，支持从外部传入（可选，暂不暴露到 UI）
- `margin`：改为 `opts.margin ?? 2`，默认 2 模块静默区
- `fontSize`：默认改为 `opts.fontSize ?? 12`

**理由**：热敏打印机分辨率低（通常 203dpi），条宽需要 >= 2px 才能清晰。`barWidth=4` 是热敏打印推荐值。

### 2. 修复 `CellBarcode.vue` — 单元格条码渲染

**文件**：`packages/print-canvas/src/components/elements/CellBarcode.vue`

**改动**：
- 新增 `barWidth` 和 `fontSize` props
- `width`：改为 `(props.barWidth ?? 4) / 2`，与渲染管线一致
- `fontSize`：改为 `props.fontSize ?? 12`
- `margin`：改为 `2`，增加静默区

**理由**：单元格条码需与独立条码元素渲染效果一致。

### 3. 补全 `TableCellGroup.vue` — 单元格条码属性面板

**文件**：`packages/print-canvas/src/components/property/TableCellGroup.vue`

**改动**：
- 在「码制」下方新增「条宽（倍率）」配置（StepperInput，min=2, max=4, step=0.5）
- 在「显示文本」下方新增「文本字号 (pt)」配置（StepperInput，min=5, max=24）
- 写入逻辑：`write(c => { c.barWidth = $event })` / `write(c => { c.fontSize = $event })`

**理由**：使单元格条码配置与独立条码元素完全一致。

### 4. 补全 `types.ts` — 单元格类型定义

**文件**：`packages/print-core/src/designer/types.ts`

**改动**：
- 在 `TableCell` 接口中新增 `barWidth?: number` 和 `fontSize?: number` 字段

**理由**：类型定义需与实际属性一致。

### 5. 补全 `data-binder.ts` — 数据绑定

**文件**：`packages/print-core/src/render/data-binder.ts`

**改动**：
- 在绑定单元格条码属性时，增加 `barWidth` 和 `fontSize` 的绑定

**理由**：确保单元格属性能传递到渲染管线。

### 6. 补全 `html-generator.ts` — HTML 渲染

**文件**：`packages/print-core/src/render/html-generator.ts`

**改动**：
- 在 `codeImgHtml` 调用时，传递 `barWidth` 和 `fontSize`（当前已传递，无需改动，但需确认 `opts` 中包含单元格属性）

**理由**：确保渲染参数正确传递。

## 假设与决策

1. **默认 `barWidth` 从 2 调整为 4**：热敏打印推荐值，存量模板若未设置 `barWidth`，打印效果会立即改善。
2. **默认 `margin` 从 0 调整为 2**：增加静默区，防止热敏打印裁切条码边缘。
3. **不暴露 `barHeight` 到 UI**：条码高度由元素高度自动控制，无需用户手动设置。
4. **单元格条码属性与独立条码元素完全对齐**：用户期望两类条码行为一致。

## 验证步骤

1. **构建验证**：`npm run build`
2. **功能验证**：
   - 创建独立条码元素，设置 `barWidth=4`，导出 PDF 用热敏打印机打印，检查清晰度
   - 创建表格，将单元格设为条码类型，设置 `barWidth=4`、`fontSize=14`，打印检查
   - 对比修改前后打印效果
3. **回归验证**：
   - 存量模板（未设置 `barWidth`）打印效果应改善（默认值从 2→4）
   - 二维码渲染不受影响
   - 浏览器预览与 PDF 导出效果一致
