worm-vue3-print · 打印设计器宿主示例总览

五个互相独立的示例工程，每个都把自己宿主接入打印设计器的全过程写在自家文件里 —— 设计器挂载、模板与字段注入、宿主回调、事件、浏览器预览打印、服务端 PDF、客户端静默打印。 没有共用壳层，照抄其中一个工程即可落到你自己的项目里。 五个页面的界面版式完全一致：样式与示例库分别由 scripts/sync-demo-styles.mjs 与 scripts/sync-demo-samples.mjs 从 demo/ 同源生成，打开任意一个页面都能用顶栏的「宿主示例」下拉切到其余四个。

⚠ 实验性质：@worm-vue3-print/common 尚未定版，接口与产物形态仍可能调整， 不建议应用到生产环境；Vue 3 项目请使用成熟方案 @worm-vue3-print/canvas （对应 demo/，端口 9303）。本组示例仅供评估与非生产环境的集成验证。

Vue 3 canvas组件版设计器

@worm-vue3-print/canvas 的 <PrintDesigner> SFC 组件，本仓库的权威示例（样式与示例库的抽取源）。

cd demo
npm install
npm run dev     # :9303
打开 →

Vue 3NPM 包接入

SFC 写法；编译期要配 isCustomElement。

cd demo-common/apps/vue3
npm install
npm run dev   # :9331
打开 →

Vue 2.7NPM 包接入

SFC 单文件组件（Options API）；ignoredElements 声明自定义元素。

cd demo-common/apps/vue2
npm install
npm run dev   # :9332
打开 →

React 18NPM 包接入

hooks + ref 赋 property + addEventListener 听 CustomEvent。

cd demo-common/apps/react
npm install
npm run dev   # :9335
打开 →

jQueryJS + CSS 直挂

无打包器：一个 <link> + 一个 <script>，业务代码只用全局 WormPrintCommon 与 $。

cd demo-common/apps/jquery
npm install     # postinstall 拷 dist 两份文件
npm run dev     # :9334（node server.mjs 纯静态）
打开 →
五个 demo 都能单独跑，本页由 node demo-common/scripts/serve-nav.mjs 挂在 :9300 （npm run nav:demo-common；npm run dev:demo-common:all 会顺带起它）。 @worm-vue3-print/common 是零框架 Web Component，设计器样式内置在组件 Shadow DOM； @worm-vue3-print/core 提供同构出纸管线（renderHtmlPages / PrintClient）。 可选依赖：npm run dev:render（服务端 PDF，:3001）、本机 print-client 桌面客户端（:17521）； 两者不在时「打印输出」弹窗显示「离线」并给出可读提示。 验收：node demo-common/scripts/verify-demo.mjs http://localhost:<端口>/（四个宿主同一套 34 项 UI 级断言）。
