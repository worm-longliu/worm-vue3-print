# 自由画布元素四向外边距设计

日期：2026-11-05
范围：`packages/print-core`、`packages/print-canvas`、`packages/print-common`、`packages/print-contract`、渲染服务与模板契约文档。

## 1. 背景与目标

当前内容区、页眉和页脚元素均使用 `position:absolute; left; top`，`width/height` 表示实际边框盒尺寸。首页保留设计坐标，跨页后由 core 分页引擎重排；画布、`common` 与出纸 HTML 分别生成定位样式，分页和交互又直接读取 `options.left/top/width/height`。

本次在不引入文档流的前提下，为元素增加上、右、下、左四向外边距，达到：

1. 保留自由拖拽、键盘移动、缩放、编组、重叠和 `zIndex` 行为。
2. `left/top` 表示外边距盒起点；左、上外边距移动实际边框盒，右、下外边距扩大外部占位。
3. 外边距不压缩 `width/height`，不推动画布中的其他元素。
4. 外边距参与吸附、对齐、分布、分页预算、越界提示和连续纸高度。
5. 未配置新字段的存量模板，模板迁移、分页产物和出纸 HTML 保持原结果。
6. 画布、浏览器预览、服务端 PDF 与桌面客户端共用 core 的同一套几何定义。

## 2. 非目标

- 不引入 CSS 文档流、自动换行或“上方内容变高后推动后续元素”。
- 不新增模板级 `layoutMode`，不维护绝对/相对两套模板模型。
- 不把外边距实现成内边距，不改变元素内容盒尺寸。
- 不新增参考元素、约束图、自动避让人群或重叠检测。
- 不改变表格单元格、流式列表内部 `flowPadding*`、条码静区等已有配置的含义。
- 不重构图层、旋转、表格分页或跟随区算法；仅替换其几何输入并补直接相关测试。

## 3. 方案选择

### 3.1 采用：绝对定位 + 原生 CSS 外边距 + core 几何单点

元素根节点继续使用 `left/top`，按配置输出 `margin-top/right/bottom/left`。绝对定位下，`left/top` 定位的是外边距边缘，浏览器原生完成实际边框盒偏移，不需要画布和出纸分别手写两套位置换算。

core 新增纯几何函数，供交互、分页、告警和其他不能直接依赖浏览器盒模型的路径使用。缺省四边距为零时，不出新 CSS 声明，几何公式退化回原公式。

### 3.2 排除：直接改为 `position:relative`

这会进入文档流并产生自动推挤，破坏自由画布、现有设计坐标与重叠能力，不符合目标。

### 3.3 排除：完整约束布局引擎

参考元素和依赖关系会引入排序、循环依赖及新的模板迁移问题，超出本次需求。

## 4. 数据契约

在 `ElementOptions` 增加：

```ts
/** 元素四向外边距，单位 mm；缺省 0，允许负数。 */
marginTop?: number
marginRight?: number
marginBottom?: number
marginLeft?: number
```

约定：

- 新字段是公开模板契约，同时被内容区、页眉、页脚元素消费。
- 缺省、`undefined` 与数值 `0` 的几何含义相同；元素工厂不主动写入这些字段。
- 属性恢复默认值时移除字段或写回 `undefined`，不要求序列化四个零值。
- UI 允许输入任意有限负数，不设置与纸张无关的固定最小值。
- 非数字、非有限数值由 `print-contract` 报告；渲染几何兜底按零处理，且不直接拼接非受控 CSS 值。
- `normalizeTemplateUnits` 将四个字段纳入旧 `pt` 模板到 `mm` 的换算；已有 `unit:'mm'` 模板不重复换算。
- `OPTION_META`、属性搜索、模板 schema、集成技能和中英文文档同步登记。

## 5. 几何定义

设元素原始配置为 `L=left`、`T=top`、`W=width`、`H=effectiveHeight`，四边距为 `mT/mR/mB/mL`。

### 5.1 实际边框盒

```text
B.left   = L + mL
B.top    = T + mT
B.right  = B.left + W
B.bottom = B.top + H
B.width  = W
B.height = H
```

实际边框盒用于可见位置、可见重叠、旋转中心和真实油墨裁切判断。缩放只改变 `W/H`，不改变四边距。

### 5.2 外边距盒

```text
M.left   = L
M.top    = T
M.right  = L + mL + W + mR
M.bottom = T + mT + H + mB
M.width  = max(0, mL + W + mR)
M.height = max(0, mT + H + mB)
```

外边距盒用于吸附、对齐、分布和分页占位。`max(0, …)` 只防止极端负边距使分页区间或预算倒挂，不修改模板值，也不纠正实际边框盒位置。

无外边距时，`M` 与 `B` 完全相等。

### 5.3 对外纯函数

在 core 增加一个小型几何模块并从 `/designer` 导出，职责限于：

- 读取并归一化四边距；
- 生成四边距 CSS 声明；全零或均未配置时返回空字符串；
- 按给定有效高度计算 `B`、`M`；
- 为分页提供 `[M.left, M.left + M.width]` 与 `M.height`。

函数不依赖 Vue、DOM、宿主业务或渲染服务。有效高度仍由现有“设计高度/浏览器实测高度”规则决定，几何模块不自行测量 DOM。

## 6. 画布与交互

### 6.1 两套设计器同源

`print-canvas/BaseElement` 与 `print-common/shell/elements` 复用 core 的边距归一化结果，按各自现有样式记录形式输出；HTML 生成器复用 core 的 CSS 声明函数。三者继续输出原有 `position/left/top/width/height/zIndex/rotate`，缺省边距时样式键和值保持原状。

### 6.2 拖拽、移动与复制

- 拖拽期间继续使用 `transform` 预览，结束时只写 `left/top`。
- `useDrag` 读取的根节点 `style.left/top` 仍是外边距盒坐标，因此不把 `marginLeft/marginTop` 再加一次。
- 键盘微移、成组拖动、Alt 复制、粘贴和层级调整不写四边距；副本继承原外边距。
- 允许移出纸面及元素重叠，不新增坐标钳制。

### 6.3 吸附、对齐与分布

这些操作统一以 `M` 为输入：

- 左/右/顶/底对齐使用 `M` 的相应边缘；
- 水平/垂直居中使用 `M` 的中心；
- 等距分布按 `M` 的总跨度和间隙计算；
- 吸附引导线落在 `M` 的边缘或中心；
- 操作结果仍写回 `left/top`，外边距不变。

可见重叠聚类不得直接使用 `M`，见第 7.2 节。

### 6.4 属性面板

“位置与尺寸”分组增加“外边距 (mm)”四输入框，顺序为上、右、下、左，复用 `StepperInput` 与四向网格。X/Y 提示为“外边距盒坐标”，W/H 提示为“不含外边距”。

`canvas` 与 `common` 的属性搜索、恢复默认值及重置提示共用 core 注册信息。

## 7. 分页、旋转与跟随区

### 7.1 普通元素与显式编组

- 横向分列区间使用 `M`；未旋转元素每次 `occupy` 的高度使用 `M.height`，旋转元素按第 7.3 节使用同口径变体。
- 首页 `renderTop=T`，保持设计坐标；跨页后 `renderTop` 仍表示外边距盒坐标，不把 `mT` 预先加进该字段。
- 新页光标先落在 `M.top`，实际边框因 CSS `margin-top` 自然位于光标下方 `mT`；下一个元素光标增加本元素的 `M.height`。
- `renderTop/groupTop` 的公开含义不变，避免 HTML 生成器重复加边距。
- 显式编组整体移页时，以成员旋转结算后的外边距占用顶/底计算统一平移量；成员相对距离、重叠和各自边距不变。
- `keepWithNext` 的组合高度与剩余预算都包含外边距。

### 7.2 隐式重叠分页单元

可见重叠仍按 `B` 的纵向区间与横向区间同时相交判定，不能因正外边距盒相交而把两个可见分离元素错误绑成同页单元。

单元整体分页时按成员 `M` 的并集计算占用；出纸继续按各成员原始相对坐标定位，负边距形成的重叠不拆开、不累加两次高度。

### 7.3 旋转

旋转发生在由 `B` 确定的实际边框盒上，中心与现有 CSS `rotate` 一致。现有 `getRotatedAabb` 输入由原始 `left/top` 盒改为 `B`，无外边距时结果不变。

设旋转外接盒为 `A`：

```text
shift = B.top - A.top
```

跨页放置时沿用现有 `renderTop = pageCursor + shift`，使 `A.top` 与新页光标之间保留 `mT`。纵向占位使用 `max(0, mT + A.height + mB)`；真实可视越界仍按 `A` 判断，外边距底部另纳入布局预算。

外边距不作为第二个旋转对象重复旋转，也不对同一偏移累计两次。

### 7.4 表格、动态列表与每页重复元素

- 独立切片的 `renderTop` 仍是锚点外边距盒顶；切片根元素输出自身外边距。
- 每页重复区的最大底边按旋转后的实际底边加 `mB` 计算，正文预算统一扣减，不能在切片和整页预算中重复扣除。
- 表格/动态列表的行高测量仍只读边框盒高度，元素外边距由分页层单独记账，不混入 `measuredRowHeights` 或 `measuredFlowRowHeights`。
- 表格列宽、单元格尺寸和行高不因外边距改变。

### 7.5 跟随区

- 锚点设计底部改为 `B.bottom`，锚点下外边距进入锚点与跟随区之间的外部占位。
- 跟随成员归属的横向交集使用 `M`，可见位置仍由成员 `B` 决定。
- 跟随区高度取成员外边距底边的并集范围，重叠成员不重复累加。
- `flow-group` 容器不能整组再套一次锚点外边距；锚点切片与跟随成员分别消费自己的外边距，避免整组重复偏移。
- `flow-follow` 内继续按设计坐标差绝对定位，保留成员重叠和 `zIndex`；容器高度包含跟随成员 `mB`。

### 7.6 越界与连续纸

- 横向、顶部和底部的真实裁切告警按 `B` 或旋转后的 `A` 计算，透明外边距本身不伪报“油墨被裁切”。
- 布局预算和分页溢出按 `M` 计算，正右/下外边距造成的占位不足必须可见。
- 连续纸探针现有 `getBoundingClientRect()` 不含外边距：只对承载新字段的元素根盒补算自身 `mB`，不得给所有内部后代统一补边距而重复计高。
- 连续纸最小高度、页脚高度和模板底边距公式保持不变。

## 8. 出纸数据流

```text
模板 JSON
  → 单位迁移/契约校验
  → core 四边距归一化
  → 画布/common 输出绝对定位 + 原生 margin
  → 浏览器测量边框盒与表格/列表行高
  → core 以 M 做预算、以 B/A 做可见几何
  → PageSection.renderTop/groupTop（外边距盒坐标）
  → 同构 HTML（绝对定位 + 同一 margin）
  → 浏览器预览 / 服务端 PDF / Electron 客户端
```

不新增第二套出纸路径，不让服务端或客户端各自解释四边距。

## 9. 兼容与错误处理

1. 未配置新字段时，不出四条 CSS 声明，原定位样式、分页 section、页数和告警保持一致。
2. 旧 `pt` 模板只在原本就带新字段时换算；无字段模板不增加序列化键。
3. 非法输入不生成 `NaNmm`、`Infinitymm` 或任意字符串样式；契约层给出字段路径，渲染层按零兜底。
4. 外边距导致的物理越界沿用现有 warning/overflow 通路，不新增异常类型。
5. 元素重叠不是错误，不新增阻断；`zIndex` 缺省仍回退模板数组顺序。
6. 不修改或放宽现有分页、旋转、固定重复和跟随区断言来迎合实现。

## 10. 测试矩阵

### 10.1 core 纯函数与契约

- 缺省/零/正值/负值四边距的 `B`、`M`、CSS 输出。
- 极端负值下预算跨度不为负，边框盒不被静默修正。
- 非法数值兜底与 `print-contract` 字段路径。
- `pt → mm` 四字段换算及 `unit:'mm'` 幂等。
- `OPTION_META` 全键漂移检查、属性搜索和恢复默认值。

### 10.2 画布与 common

- 四边距样式在两套设计器中一致，缺省不增加样式键。
- 拖拽、成组拖动、键盘移动后不重复累计左/上边距。
- 缩放只改 W/H；复制和粘贴继承边距。
- 对齐、居中、分布和吸附按 `M`，并验证 `left/top` 回写。
- 正边距不推动其他元素，负边距与坐标可形成重叠。

### 10.3 分页与 HTML

- 普通元素首页坐标、跨页光标、`keepWithNext` 和二维横向分列包含外边距。
- 显式/隐式编组整体移页后保持相对位置与重叠。
- 旋转 90/180/270 度的偏移、AABB、预算和告警不重复计边距。
- 表格切片、动态列表切片、每页重复区、汇总和跟随区均覆盖正/负边距。
- 连续纸探针包含元素 `mB`，且不重复计算内部后代边距。
- 存量模板做分页产物深比较和 HTML 字节比较。

### 10.4 真实渲染验收

通过 `services/print-render` 的 Chromium + pdfjs 几何断言验证：

- 左/上边距改变实际文本或图形坐标，W/H 不变。
- 右/下边距不移动边框盒，但影响预算或连续纸高度。
- 两个元素按设计重叠时 PDF 中仍重叠，层序正确。
- 跨页元素保留上/下外边距，不侵入页眉、每页重复区或页脚。
- 至少一个表格跟随区与一个旋转元素覆盖真实 PDF 坐标。

执行根工作区构建、测试、架构检查，以及 render 工作区测试。Electron 真机 PDF 若未提供，明确记为未覆盖，不能以浏览器或服务端结果冒称已验证。

## 11. 预期改动边界

- core：元素类型、单位迁移、新几何模块、对齐交互、分页、HTML/CSS、连续纸探针及测试。
- canvas/common：根元素样式、吸附/对齐输入、位置属性面板及测试。
- contract：字段元数据和校验测试。
- render：真实 PDF 几何集成测试。
- 文档与技能：模板字段、单位、负边距、重叠和兼容说明。

不得把改动扩展到无关 UI、表达式引擎、条码、拼版或发布流程。
