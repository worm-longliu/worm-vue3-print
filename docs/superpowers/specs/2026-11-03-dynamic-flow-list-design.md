# 动态流式列表容器设计

> 状态：**已实施（2026-11-03）**，验证记录见第十节；本文第九节保留为验证方案。
> 日期：2026-11-03。
> 前置文档：`2026-10-22-flow-list-element-design.md`。本文只扩展动态模式；固定模式的既有契约不变。

## 一、目标与范围

现有 `flowList` 将每条数组数据渲染为一个文本块，支持固定列数、最小行高、横向间距、自动跨列和最大跨列数，但容器采用“一框一页、超高裁切”。本需求为其增加可选的动态容器能力：

- 块内本期仍只支持文本，不引入通用嵌套元素或子画布。
- 容器高度由实际内容撑开，固定纸内容满页后按行续页。
- 容器支持四边内边距，每个分页切片都绘制完整边框。
- 列表换行、自动跨列和最大跨列规则与现有实现一致。
- 列表下方元素复用表格跟随区规则，避免动态内容覆盖后续内容。

不在本期范围内：图片、条码、表格等块内子元素，块级独立样式编辑器，任意嵌套容器，以及固定模式行为调整。

## 二、兼容策略

采用现有元素增加布局模式的方式，不新增公开元素类型：

```ts
flowLayoutMode?: 'fixed' | 'dynamic'
flowPaddingTop?: number
flowPaddingRight?: number
flowPaddingBottom?: number
flowPaddingLeft?: number
```

- 缺省模式为 `fixed`，新拖入的 `flowList` 也默认 `fixed`。
- `fixed` 保持现有设计高度、裁切、HTML 结构和分页行为，旧模板无需迁移。
- `dynamic` 启用自动高度、四边内边距和分页。
- 四项内边距单位为 mm，缺省为 `0`；非有限值和负数按 `0` 处理，不回写作者的其他配置。
- 边框、背景、字体、对齐等继续复用现有元素属性，不新增一套容器样式字段。

不采用“全部改为动态”或“新增 dynamicFlowList 元素”：前者破坏旧模板输出，后者会复制两套属性与渲染实现。

## 三、数据绑定与行结构

每条数据仍通过现有 `formatter` 求值，列表源检出和 `dataSource` 显式覆盖规则不变。`layoutFlowList` 继续负责列宽估算、自动跨列和占位换行。

动态模式在数据绑定后保留内部 `_flowRows` 行结构。每行包含已有文本块及其 `span`，不把行结构暴露为新的模板元素契约。测量产物 `MeasuredElement` 增加可选的 `measuredFlowRowHeights`，记录文本换行后的每行真实高度。

出纸测量趟需要让每行具有可独立测量的 DOM 标记。行高仍为最小高度语义：实际行高取 `flowRowHeight` 与内容自然高度的较大值。容器内容宽度扣除左右内边距后再参与列宽与跨列计算。

固定模式不依赖新增的逐行测量数据，避免为兼容模式增加额外分页条件。

## 四、动态渲染与分页

`PageSection` 增加 `flow-list-slice` 类型，并以 `startFlowRow`、`endFlowRow` 表示本片的半开行区间。只有动态模式产生该切片；固定模式仍走普通 `element`。

### 4.1 切片规则

- 以现有排布后的“行”为最小分页单位，不拆行，也不拆跨列文本块。
- 首页从元素设计 `top` 开始；续页从内容区顶部 `0` 开始。
- 每片可用高度均扣除本片上下内边距和上下边框的物理高度。
- 当前行放不下时，先结束已有切片并换页；不在页尾留下只有边框的空容器。
- 单行自身超过整页可用高度时，沿用表格策略：保留该行并标记页面 `overflow`，不制造空白页或死循环。
- 连续纸保持单片渲染，最终纸高由完整内容推导。
- 空数据、缺省演示数据和 `testData` 的现有解析口径不变。

### 4.2 每页容器

每个切片独立输出一个容器，容器包含本片所有行。容器高度由行高、内边距和边框实际决定，不使用原固定设计高度裁切内容。

边框在切片外层闭合，因此首页、中间页和末页均有完整四边边框；不能通过 CSS 分页断点依赖浏览器补边。背景也只作用于当前切片容器。

动态模式下，元素整体高度不再作为内容上限；设计高度仅作为画布初始尺寸，实测后由真实内容高度取代。

## 五、跟随区与元素分页关系

将现有“表格 → 跟随区”判定泛化为“可分页动态元素 → 跟随区”，动态 `flowList` 与表格使用同一套规则：

- 按画布顺序查找上方最近的可分页动态元素。
- 成员设计 `top` 必须不小于动态元素设计底部，且二者横向区间有交集。
- 显式编组成员仍不进入隐式跟随区。
- 跟随区只接在最后一个列表切片之后；中间页不重复。
- 跟随区能放入末片所在页则同页承接，否则整体移到下一页。
- 动态 `flowList` 自身按可切片元素处理，不再进入普通非表格元素的堆叠组或绝对定位整体分页，避免重复记账。

设计底部使用画布回写后的实际高度；没有可靠实测值时，以现有配置可推导的高度兜底。`flow-group` 渲染需要同时承接表格切片与动态列表切片，但不能改变现有表格跟随区的输出。

## 六、设计器行为

`print-canvas` 与 `print-common` 的“流式列表”属性组同步增加：

- 布局模式：固定高度、动态分页。
- 动态模式下显示上、右、下、左四项内边距。
- 固定模式不显示动态内边距，不改变现有面板字段顺序与行为。

动态模式下，设计画布展示实际文本行并测量内容高度，将毫米高度回写到 `options.height`，使选中框、位置标签、吸附和跟随区设计底部使用同一尺寸。画布仍不运行分页引擎，分页结果以预览和出纸为准。

自动跨列继续遵循现有设计器口径：画布不预演出纸侧估算跨列，出纸与预览以 `layoutFlowList` 的结果为准。动态模式只增加真实高度测量，不把第二套跨列算法引入画布。

## 七、模块落点

### `packages/print-core`

- `designer/types.ts`、`element-factory.ts`：模式与四边内边距字段、默认值。
- `render/flow-list.ts`：模式、内边距解析及动态内容宽度计算。
- `render/data-binder.ts`：保留动态行结构。
- `render/types.ts`：逐行测量与列表切片类型。
- `print/measure.ts`：读取真实行高。
- `render/pagination-engine.ts`：动态列表切片、页面预算、跟随区泛化。
- `render/html-generator.ts`：逐行测量标记和独立闭合的切片容器。
- 属性注册与导出：字段说明、搜索及两个设计器外壳共用解析函数。

### `packages/print-canvas` 与 `packages/print-common`

同步实现模式属性、四边内边距和动态高度测量，保持既有类名、属性组键和外壳能力一致。

### 文档

更新中英模板设计器文档、字段说明、变更记录及原流式列表设计文档的实施指引。无需修改 SDK、宿主业务字段契约或新增工具箱元素。

## 八、异常与边界

- 非法布局模式按 `fixed` 处理，确保未知或旧数据不会意外分页。
- 内边距压缩内容宽度时不自动减少列数或修改间距；沿用现有“只提示、不擅改配置”的原则。
- 内边距与边框必须进入分页预算，不能出现内容放得下一个整行、加上容器边距后却越过页底的情况。
- 动态列表与表格一样忽略元素级旋转，不扩展旋转分页模型。
- 块内表达式错误、数据绑定错误继续沿用现有渲染错误处理，不因动态模式另设一套语义。

## 九、验证方案

### core 单元与集成测试

1. 缺省和显式 `fixed` 的既有输出、裁切与分页不变。
2. 动态绑定保留正确行结构，逐行测量对应真实文本换行高度。
3. 固定列数、横向间距、自动跨列、最大跨列及换行结果与现有算法一致。
4. 首页和续页切片区间连续、无重复、无遗漏、无空白页。
5. 四边内边距和边框进入页面预算，每片均输出完整容器。
6. 单行超高标记 `overflow`，连续纸保持单片。
7. 跟随区同页承接、末页不足时整体移页，中间页不重复。
8. 表格既有分页和跟随区回归测试全部通过。

### 两个设计器外壳

覆盖模式切换、动态字段显隐、四边值写入、固定模式兼容、动态高度回写，以及画布不预演跨列的既有约定。

### 真实渲染

运行渲染服务的 Playwright 测试，构造多行、长文本、跨列、四边内边距及下方跟随元素，验证：

- 实际页数与每页文本区间；
- 文本块和跨列行没有被页界拆开；
- 每个列表切片四边边框均存在且闭合；
- 跟随元素只出现在末片之后；
- 浏览器、服务端和桌面客户端继续共用 core 渲染结果。

最终执行相关 workspace 测试、`npm run test -w @worm-vue3-print/render`、`npm test`、`npm run build`，并通过 `git diff` 检查包边界、类型、兼容性和无关改动。

## 十、实施与验证记录（2026-11-03）

### 已落地能力

- `flowLayoutMode` 缺省 `fixed`，非法值按 `fixed` 处理；`fixed` 保持原有设计高度、裁切、HTML 结构与「一框一页」行为。
- `dynamic` 模式保留内部 `_flowRows`，按真实文本行测量并在满页后切片续页；整行为最小分页单位，不拆行也不拆跨列单元；单行超高按 `overflow` 口径留在当前页。
- 四边内边距 `flowPaddingTop/Right/Bottom/Left`（mm，缺省 `0`，负值与非有限值按 `0`）仅 `dynamic` 消费，左右值参与内容宽度、列宽与跨列计算。
- 每个 `flow-list-slice` 独立输出容器并带完整四边边框；动态列表与表格共用跟随区判定，跟随区只接在末片之后。
- 固定列数、行高、间距、自动跨列与最大跨列沿用原有 `layoutFlowList` 逻辑；画布仍不预演跨列、不运行分页引擎。
