# 打印模板设计器帮助文档系统设计

## 概述

为 `@worm-vue3-print/canvas` 打印模板设计器添加帮助文档功能，通过顶部工具栏的帮助按钮打开模态框，提供全面的使用指南和参考文档。

## 目标

- 所有用户（新手和有经验的用户）都能快速上手设计器
- 提供功能参考文档，减少学习成本
- 支持多种文档格式（快速入门、功能说明、快捷键、FAQ）

## 组件设计

### 1. HelpButton 组件

**位置**: `packages/print-canvas/src/components/HelpButton.vue`

**功能**: 
- 显示帮助图标（`?` 或问号）
- 点击触发帮助模态框显示
- 支持 tooltip 提示

**Props**: 无

**Events**:
- `click`: 点击按钮时触发

### 2. HelpModal 组件

**位置**: `packages/print-canvas/src/components/HelpModal.vue`

**功能**:
- 显示帮助文档模态框
- 标签页导航
- 内容展示区域
- 关闭按钮

**Props**:
- `visible: boolean` - 控制模态框显示/隐藏
- `initialTab?: 'getting-started' | 'features' | 'shortcuts' | 'faq'` - 初始显示的标签页（可选）

**Events**:
- `close`: 关闭模态框时触发
- `update:tab`: 标签页切换时触发

### 3. 帮助内容模块

**位置**: `packages/print-canvas/src/help-content/`

**结构**:
```
help-content/
├── index.ts          # 内容导出
├── getting-started.ts # 快速入门
├── features.ts       # 功能说明
├── shortcuts.ts      # 快捷键
└── faq.ts           # 常见问题
```

## 文档内容结构

### 快速入门

1. **界面布局介绍**
   - 左侧面板：字段树、图层管理
   - 中间画布：设计区域、标尺、参考线
   - 右侧面板：属性设置、模板配置
   - 顶部工具栏：常用操作
   - 底部状态栏：坐标、缩放、元素数量

2. **添加第一个元素**
   - 从左侧面板拖拽元素到画布
   - 选择元素类型（文本、图片、条码等）
   - 调整位置和大小

3. **数据绑定基础**
   - 使用 `{field.path}` 语法绑定字段
   - 打开表达式编辑器配置绑定
   - 预览数据绑定效果

4. **保存与预览**
   - 保存模板为 JSON 格式
   - 预览打印效果
   - 导出模板

### 功能说明

1. **元素类型**
   - 文本元素：静态/动态文本
   - 长文本：多行文本，支持自动换行
   - 数据表格：动态行列、分页
   - 条形码/二维码：多种编码格式
   - 图片：静态/动态图片
   - 线条/形状：装饰元素
   - HTML：自定义 HTML 内容
   - 页码：自动页码
   - 水印：防伪/标识水印

2. **表达式编辑器**
   - 基础表达式语法
   - 格式化函数
   - 条件判断
   - 数据转换

3. **数据表格配置**
   - 列定义与数据绑定
   - 动态行高
   - 分页设置
   - 表头重复
   - 序号/小计/汇总

4. **对齐与吸附**
   - 自动对齐线
   - 网格吸附
   - 元素对齐操作

5. **图层管理**
   - 图层顺序调整
   - 显示/隐藏元素
   - 锁定/解锁元素

| Ctrl+Shift+Z | 重做 |

| Ctrl+A | 全选元素 |

### 常见问题

1. **如何调整纸张大小？**
   - 右侧面板 → 页面设置 → 纸张大小
   - 支持 A4、A5、Letter 等预设
   - 支持自定义尺寸

2. **如何处理分页？**
   - 数据表格自动分页
   - 设置每页显示行数
   - 跨页重复表头

3. **如何导入外部数据？**
   - 通过 `fields` prop 传入字段定义
   - 通过 `initialTemplate` prop 加载模板
   - 使用 `loadDefaultTemplate` 回调加载默认模板

## 样式规范

- 模态框样式遵循项目现有的 CSS 变量
- 使用 `--pd-bg`、`--pd-surface` 等颜色变量
- 圆角和阴影保持一致
- 响应式设计，支持不同屏幕尺寸

## 状态管理

- 使用 localStorage 存储帮助文档阅读状态
- 键名: `worm-print-help-read`
- 记录用户最后阅读的标签页位置

## 实现优先级

1. **P0 - 核心功能**
   - HelpButton 组件
   - HelpModal 组件
   - 基础文档内容

2. **P1 - 增强功能**
   - 搜索功能

3. **P2 - 可选功能**
   - 文档内链接跳转

   - 多语言支持
