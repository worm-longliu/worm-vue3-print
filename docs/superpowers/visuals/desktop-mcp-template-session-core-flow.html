接入鉴权：MCP 只对本机 Agent 开放

Agent 向 127.0.0.1 的 /mcp 发送 POST。MCP 未启用返回 404；启用后必须带 Bearer 配对 token，缺失或错误返回 401，且与打印安全开关无关。

  • Host 必须严格等于 127.0.0.1:<实际端口>
  • GET / DELETE 返回 405；请求体上限 4 MiB
  • 桌面工具集不提供 print_render_preview
revision 冲突：浏览器发现 baseRevision 已变，返回 REVISION_CONFLICT，画布不变；Agent 重新 get 后再 apply。
写回前门禁：契约校验、封禁元素（含 pages/header/footer）、4 MiB 上限全部在触达浏览器前完成。
