## 项目介绍

worm-vue3-print 是一个 monorepo（npm workspaces）：

- `packages/print-core`（`@worm-vue3-print/core`）：模板表达式引擎与同构渲染管线，纯 TypeScript
- `packages/print-canvas`（`@worm-vue3-print/canvas`）：Vue 3 可视化设计器与浏览器预览
- `packages/print-client-sdk`（`@worm-vue3-print/client`）：静默打印浏览器端 SDK
- `services/print-render`（`@worm-vue3-print/render`）：Playwright PDF/截图渲染微服务
- `clients/print-client`（`@worm-vue3-print/print-client`）：Electron 跨平台静默打印客户端
- `demo`：设计器 + 预览 + 服务端 PDF + 静默打印完整集成示例

提供能力：

- 可视化模板设计器：拖拽、吸附、标尺、图层、多选组合、撤销重做
- 数据绑定与表达式引擎（safelist 安全执行）、格式化与聚合函数
- 智能表格：动态分页、跨页重复表头、序号/小计/汇总、单元格图片与条码
- 同构渲染：一套渲染逻辑支撑浏览器预览、服务端 PDF、桌面客户端出纸
- 静默打印：本机回环 WebSocket + Electron，无打印对话框，支持连续纸纸高自动推导
