## 完整口播稿

### 开场钩子（约 20s）

**【画面】工程化背景 / 打印页面瞬间切换到项目首页 logo**

【旁白】
做企业打印系统，最头疼的是什么？打印模板做起来麻烦，浏览器里看到的和真正打出来的还不一样。今天给你介绍一个开源项目——worm-vue3-print，让打印模板的设计和输出，变得简单又可靠。

---

### ① 可视化设计器（约 50s）

**【画面】进入设计器，手持鼠标：拖入文本框→拖动位置→展示吸附/对齐参考线→打开图层面板→撤销重做**

【旁白】
先从最直观的说起——这是一个可视化的打印模板设计器。你不需要写代码，直接把元素拖到画布上就行。

拖动的时候，它有吸附、对齐、参考线，帮你把版式排得整整齐齐。左边是图层面板，编辑层次结构一目了然。做错了也不怕，支持撤销和重做。

单位直接是毫米，按 A4 等真实纸张规格精确排版，所见即所得。

---

### ② 元素库（约 40s）

**【画面】逐个展示：文本、长文本、数据表格、条形码、二维码、图片、线条、形状、HTML、页码、水印**

【旁白】
模板里能用到的元素，这里基本都齐了。文本、长文本、数据表格；业务必备的条形码和二维码；还有图片、形状、页码、水印。

从普通的单据，到带条码标签、甚至带到水印的正式文书，都能在一个模板里搞定。

---

### ③ 数据绑定与表达式（约 45s）

**【画面】选中某字段，演示数据绑定 `{field.path}` → 演示一条表达式 → 展示格式化效果**

【旁白】
关键的是，模板里的元素可以和真实数据绑定。

把字段拖进模板，填入格式，数据一来就自动填充。需要复杂一点？内置的表达式引擎支持字段求值、格式化和安全执行——它在一个安全的范围内运行，保证数据不会乱跑，结果稳定可控。

这是给技术朋友的话：这套逻辑是独立、纯粹、无宿主依赖的，浏览器和后端跑的是同一套能力。

---

### ④ 智能表格（约 45s）

**【画面】展示数据表格：数据多了自动分页→跨页重复表头→演示序号/小计/汇总→单元格合并**

【旁白】
做打印单，表格是重头戏。这张智能表格，数据量再大也不怕——超出页面自动分页，翻页之后表头还会自动重复。

行列序号、小计、汇总，这些单据里最常见的统计，都有内置支持；需要特殊版式？单元格还能合并。

---

### ⑤ 同构渲染管线（约 30s）

**【画面】左右分屏：浏览器预览 vs 服务端生成结果，逐屏对齐，展示一致性**

【旁白】
最后说说为什么打印结果能保持可靠。

这个项目采用同构渲染的方案——就是一套渲染逻辑，同时产出浏览器预览和最终的 HTML 输出。你在屏幕上调好的每个细节，打印出来、或者后端生成 PDF 时，都和预览完全一致。

不再有"屏幕上是这样、打出来是那样"的痛苦。

---

### ⑥ 开源价值 / 结尾（约 30s）

**【画面】项目主页：包结构（core/canvas）、License: MIT；最终定格 logo + GitHub 地址**

【旁白】
而这一切，是插在任意 Vue 3 项目里就能用的。纯 Vue 3 实现，不依赖任何 UI 组件库，安装即可接入。整个项目按清晰的分层边界组织：底层是纯逻辑的核心，上层是可视化设计器，两者解耦，方便你按需集成。

它是 MIT 协议开源的，欢迎你直接使用、提建议，甚至成为贡献者。想给企业打印减负，就从 worm-vue3-print 开始。我们月内发布稳定版，敬请期待。
