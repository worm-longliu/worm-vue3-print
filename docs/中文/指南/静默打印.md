# 静默打印（桌面打印客户端）

worm-vue3-print 内置跨平台（Windows / Linux / macOS）静默打印能力，由「桌面打印客户端 + 浏览器端 SDK」两部分组成，实现**无系统打印对话框**直接出纸，不依赖浏览器插件。

```
宿主 Web 页面（浏览器）
   │  @worm-vue3-print/core/browser（两遍渲染：测量 → 分页 → 最终 HTML）
   │  @worm-vue3-print/core/client（SDK：端口探测 / 重连 / 超时 / 鉴权）
   ▼  WebSocket（仅绑定 127.0.0.1，默认端口 17521）
桌面打印客户端（Electron，工位电脑本机运行）
   └─ printToPDF（纸张微米→英寸、保留背景/零边距）→ 系统命令打印 PDF → 物理打印机
```

> 推荐链路（`printHtml`）：模板渲染在浏览器页面内完成，客户端只负责静默出纸。
> 旧链路（`print`，客户端内渲染）继续保留兼容，无需立即改造存量接入。

## 一、安装并运行桌面打印客户端

客户端是 monorepo 内私有工作区包（`clients/print-client`，不发布 npm），以绿色目录或安装包形式分发，需在业务工位电脑上安装并运行（驻留系统托盘）。

```bash
npm run pack:client        # 仓库根构建：产出 macOS / Windows 安装包
npm run pack:client:dir    # 绿色目录版（免安装，各平台只能打包本平台）
```

- 客户端启动后驻留托盘，仅监听本机回环地址 `127.0.0.1`，默认从端口 `17521` 起探测（被占用则 +1）。
- 配置窗口提供：端口、开机自启、日志级别、安全开关、任务记录、日志查看、测试打印。
- 托盘菜单：显示窗口 / 测试打印 / 退出。

## 二、浏览器端接入

### 1. SDK 导入

SDK 随 core 提供，无需单独安装：

```ts
import { PrintClient } from '@worm-vue3-print/core/client'
```

SDK 框架无关（纯 TypeScript），浏览器与客户端必须同一台电脑。

### 2. 连接、枚举打印机

```ts
import { PrintClient, WormPrintError } from '@worm-vue3-print/core/client'

const client = new PrintClient()
client.onStatusChange((s) => {
  // 'disconnected' | 'connecting' | 'connected'，用于 UI 提示在线状态
})

await client.connect()                        // 自动探测端口并握手
const printers = await client.listPrinters()  // 枚举本机打印机
```

### 3. 浏览器预渲染 + 静默打印（推荐：`printHtml`）

页面内安装 core（与设计器同一套同构管线），先在浏览器完成两遍渲染，再把最终 HTML 直送客户端：

```bash
npm install @worm-vue3-print/core
```

```ts
import { renderHtmlPages, browserCodeRenderer } from '@worm-vue3-print/core/browser'
import type { PrintTemplateData } from '@worm-vue3-print/core'

// 页面内两遍渲染：隐藏 iframe 测量 → 分页 → 最终多页 HTML（连续纸自动探针推导纸高）
const rendered = await renderHtmlPages(
  templateJson as PrintTemplateData,
  printData,
  baseUrl,                     // 相对路径图片基址
  browserCodeRenderer,         // jsbarcode/qrcode 码制渲染
)

const { jobId } = await client.printHtml(
  rendered,                    // { html, paperMm, continuous, pageCount }
  {
    printerName: printers[0]?.name,   // 缺省走系统默认打印机
    copies: 1,
    // paperName: '…',                 // 驱动纸型名（针式打印机优先）
    // color, pageRanges, timeoutMs
  },
)
```

`printHtml` 的纸张尺寸、方向、边距、连续纸高度已全部固化在渲染产物中，**只允许**配置：`printerName`、`copies`、`paperName`、`color`、`pageRanges`、`timeoutMs`；传入 `paperSize`/`margins`/`landscape` 会被客户端以 `INVALID_REQUEST` 拒绝。HTML 载荷上限 20MB（模板图片走 URL，不内联）。

> 该链路下客户端不持有模板渲染内核，core 升级只需更新业务页面，不必重新分发客户端。

### 4. 客户端内渲染（兼容链路：`print`）

存量接入可继续把模板 JSON 与数据直接发给客户端，由客户端内部渲染：

```ts
const { jobId } = await client.print(templateJson, printData, {
  printerName: printers[0]?.name,             // 缺省走系统默认打印机
  copies: 1,
})
```

`print()` 支持配置：`printerName`、`copies`、`paperName`（驱动纸型）、`paperSize`（微米覆盖）、`landscape`、`color`、`margins`、`pageRanges`、`baseUrl`（相对路径图片基址）、`timeoutMs`。

> 长度单位均为微米（μm）：1mm = 1000μm。

### 5. 连续纸（热敏 / 标签）

模板页面属性纸张选择「连续纸」后（默认纸宽 80mm），渲染管线会按内容**自动推导出纸高度**（真实浏览器布局探针，覆盖动态表格、合计签名等），无需传纸高。

- 推荐链路：浏览器侧 `renderHtmlPages` 完成探针推导，纸高随 HTML 一起固化，无需额外参数；
- 兼容链路：仅在真机走纸公差不满足时用逃生门显式覆盖：

```ts
await client.print(templateJson, data, { paperSize: { width: 58000, height: 180000 } })
```

### 6. 打印配置由宿主维护

客户端不持久化业务打印配置。建议在宿主浏览器侧按模板保存「打印机 / 份数 / 纸张」，打印时随任务下发：

```ts
localStorage.setItem(`print:cfg:${templateId}`, JSON.stringify({ printerName: '热敏-80', copies: 1 }))
```

### 7. 安全配对（可选）

客户端默认关闭安全开关（开箱即用，仅绑定回环）。共享电脑或不可信网页环境，可在客户端配置窗口开启安全开关：

1. 客户端生成随机配对 token，在配置窗口展示；
2. 宿主页面调用一次 `pair(token)`（token 存入浏览器 localStorage，后续自动携带）：

```ts
client.pair('粘贴配置窗口展示的 token')
```

未配对或 token 错误会被客户端拒绝（`UNAUTHORIZED`）。白名单非空时同时校验浏览器 Origin。

### 8. 错误码

失败时抛 `WormPrintError`，按 `err.code` 程序化处理：

| code | 含义 |
|---|---|
| `CLIENT_NOT_RUNNING` | 未发现/断开客户端（断线期间不排队，宿主侧重试） |
| `CLIENT_TIMEOUT` | 请求超时未响应 |
| `INVALID_REQUEST` | 请求格式/字段校验失败 |
| `UNAUTHORIZED` | 安全开关开启后 token/Origin 校验失败 |
| `PRINTER_NOT_FOUND` | 指定打印机不存在 |
| `PRINTER_OFFLINE` | 打印机离线/不可用 |
| `BUSY` | 已有任务打印中（客户端串行，不排队）→ 延时重试 |
| `RENDER_TIMEOUT` | 模板渲染超时（默认 30s） |
| `PRINT_FAILED` | 系统打印接口失败 |
| `INTERNAL` | 其他内部错误 |

```ts
try {
  await client.print(template, data, opts)
} catch (e) {
  if (e instanceof WormPrintError && e.code === 'BUSY') {
    // 提示稍后重试，或宿主侧入队
  }
}
```

### 9. 自动重连

- 断线（如客户端重启）后 SDK 指数退避重连，恢复后自动可用；
- 通过 `onStatusChange` 在 UI 展示客户端在线状态。

## 三、常见问题

- **`CLIENT_NOT_RUNNING`**：本机未运行客户端，或浏览器与客户端不在同一台电脑。
- **`UNAUTHORIZED`**：安全开关开启后未配对，或 Origin 不在白名单。
- **`PRINTER_NOT_FOUND`**：打印机名不在枚举列表，先 `listPrinters()` 取真实名称。
- **静默结果与预览不一致**：模板所用字体需在客户端电脑安装。注意字体不仅影响文字换行，还会改变条码 SVG 的固有宽度（`jsbarcode` 宽度取 `ceil(max(文字宽, 条码宽))`），因此三端字体不同时条码在框内的实际尺寸仍可能有差异。
- **水印被放大/位置偏移/平铺错乱**：水印必须以「显式矢量瓦片」渲染（每块一个 `<svg class="watermark-tile">`），不得使用 CSS 平铺背景——后者会被 Chromium 编译成 PDF 平铺图案，出纸链路的 RIP 会忽略图案矩阵。排查与验证口径见故障排查文档「水印在预览/PDF 里正常，但打印到纸上被放大/错位/平铺错乱」。
- **出纸方向与浏览器/预览不一致（横向被打成纵向）**：客户端出纸时会显式向打印系统声明纸张（`-o media=…`：宿主指定纸型 > 标准纸型匹配 > `Custom.<宽>x<高>`）。若仍不一致，用 `pdfinfo` 看产物 PDF 的 `/Rotate`，并在客户端日志中核对下发的 `media` 值；针式等驱动有预置纸型时请在宿主侧传 `paperName`。
- **判断颜色/方向问题出在生成 PDF 还是打印机**：在配置窗口勾选「保留生成的 PDF」（可指定目录），任务记录会显示每份 PDF 的绝对路径。用阅读器打开该 PDF 核对：PDF 里就是黑白的 → 问题在渲染/打印链路；PDF 是彩色的 → 问题在打印机或驱动（如驱动默认单色、`print-color-mode` 需在队列侧开启）。
- **连续纸末尾留白/裁切**：驱动对纸高有步进/舍入时显式传 `paperSize.height`。
- **macOS 首次打不开**：绿色版未签名，右键 → 打开。
