# 表达式引擎

core 包内置自研的轻量表达式引擎，用于模板元素中的数据绑定与动态文本。
引擎由词法分析（`lexer.ts`）、语法分析（`parser.ts`）、求值器（`evaluator.ts`）三部分组成，
**不使用 `eval` / `new Function`**：表达式只能访问你显式传入的数据上下文与已注册函数，
无法触达全局对象、文件系统或任意 JavaScript 能力，模板可安全来自不可信来源。

## 一、绑定语法

在任意支持文本的元素属性（如文本内容、格式化文本）中，用单花括号嵌入表达式：

```
供应商：{supplier.name}
数量：{qty}，单价：{price}，合计：{qty * price}
大写金额：{UPPER(amount)}
日期：{DATE(printDate, 'YYYY-MM-DD')}
第 {pageIndex} / {totalPages} 页
```

- 花括号外为字面文本，花括号内为表达式；
- 字段路径支持点号成员访问，如 `{supplier.contact.phone}`；
- 单个表达式求值失败时，渲染管线保留原文（如 `{badExpr}`），不中断整单渲染。

## 二、表达式能力

| 类别 | 示例 |
|---|---|
| 字面量 | 数字 `123`、字符串 `'A4'` / `"A4"`、布尔 `true` / `false` |
| 变量与路径 | `amount`、`supplier.name`、`rows[0].qty` |
| 算术 | `qty * price + tax`、`(a + b) / 2` |
| 比较与逻辑 | `amount >= 1000`、`a > 0 && b < 10`、`!flag` |
| 三元 | `amount > 1000 ? '大额' : '普通'` |
| 函数调用 | `MONEY(amount)`、`IF(x > 0, x, 0)` |
| 数组 / 对象字面量 | `[1, 2, 3]`、`{ a: 1 }`（高级用法） |

## 三、TemplateEngine API

从 core 主入口导入：

```ts
import { TemplateEngine } from '@worm-vue3-print/core'

const engine = new TemplateEngine()

// 纯表达式求值
engine.evaluate('1 + 2', {})                       // 3
engine.evaluate('supplier.name', {                 // 'ACME'
  supplier: { name: 'ACME' },
})

// 模板字符串渲染：{expr} 内求值，外部为字面文本
engine.render('金额: {amount} 元', { amount: 100 }) // '金额: 100 元'

// 注册自定义函数（全局大写名约定）
engine.registerFunction('MONEY', (x: number) => Number(x).toFixed(2))
engine.render('{MONEY(amount)}', { amount: 1234.5 }) // '1234.50'
```

构造参数：

```ts
new TemplateEngine({
  functions: {                       // 初始函数表
    MONEY: (x: number) => x.toFixed(2),
  },
})
```

底层 API 也可单独使用：`tokenize`、`parse`、`evaluate`、`compileTemplate`、`getByPath`，
以及类型 `ASTNode`、`ExprFunction`、`EngineOptions`，均从 core 主入口导出。

## 四、渲染管线内置函数

设计器模板经过同构渲染管线时（浏览器预览 / 服务端 PDF / 桌面客户端），
除引擎本身外还注册了以下函数（见 `render/expression-eval.ts`）：

**格式化函数**

| 函数 | 说明 | 示例 |
|---|---|---|
| `MONEY(x)` | 千分位 + 两位小数 | `MONEY(1234.5)` → `1,234.50` |
| `DATE(d, fmt)` | 日期格式化，占位符 `YYYY MM DD HH mm ss` | `DATE(now, 'YYYY-MM-DD')` |
| `UPPER(x)` | 数字转人民币大写金额 | `UPPER(100)` → `壹佰元整` |
| `IF(cond, a, b)` | 条件取值 | `IF(qty > 0, qty, 0)` |
| `CONCAT(...)` | 拼接非空参数 | `CONCAT('a', 'b')` → `ab` |
| `IFEMPTY(v, d)` | 空值（null/undefined/空串）兜底 | `IFEMPTY(remark, '无')` |
| `ROUND(n, d)` | 四舍五入到 d 位小数 | `ROUND(3.1415, 2)` → `3.14` |
| `LEN(s)` | 字符串长度 | `LEN(name)` |

**聚合函数（表格汇总/小计）**

模板文本中以字段名为参数，渲染时自动按当前表格数据行（上下文 `rows`）预处理为数值：

| 函数 | 说明 |
|---|---|
| `SUM(field)` | 对明细行字段求和 |
| `AVG(field)` | 平均值 |
| `COUNT(field)` | 计数 |
| `MIN(field)` / `MAX(field)` | 最小 / 最大值 |

```
本页小计：{SUM(amount)}    数量合计：{SUM(qty)}    品种数：{COUNT(goodsName)}
```

core 主入口同时导出这些基础函数实现：`formatMoney`、`formatDate`、`toUpperCaseAmount`、
`ifFn`、`sum`、`avg`、`count`、`min`、`max`，可在宿主自有逻辑中复用。

## 五、系统变量

由渲染管线在数据绑定时注入（`render/data-binder.ts`）：

| 变量 | 含义 |
|---|---|
| `{printDate}` | 打印日期，格式 `YYYY-MM-DD` |
| `{printTime}` | 打印时间，格式 `HH:mm:ss` |
| `{pageIndex}` | 当前页码（测量趟以占位值 0 处理，最终渲染时替换） |
| `{totalPages}` | 总页数（同上） |

注意：`{pageIndex}` / `{totalPages}` 依赖分页结果，管线采用「测量 → 分页 → 最终渲染」
两遍处理，表格动态行展开等场景也由同一机制保证取值与最终分页一致。

## 六、宿主直接使用数据绑定

若不用设计器、只做程序化渲染，可直接使用 core 导出的绑定与渲染函数：

```ts
import {
  bindData,
  injectSystemVariables,
  generateHtml,
  paginate,
} from '@worm-vue3-print/core'
```

完整函数清单见 [API 文档](../接口/API文档.md)。
