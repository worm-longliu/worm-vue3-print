# 快速开始

本指南帮助你在 10 分钟内把打印模板设计器接入 Vue 3 项目，并跑通浏览器预览。
静默打印（桌面客户端）与服务端 PDF 的接入见各自专题文档。

## 一、项目与包说明

worm-vue3-print 是 npm workspaces monorepo，npm 上提供 core 与 canvas 两个包（随主版本同步发布）：

| 包名 | 定位 | 环境 |
|---|---|---|
| `@worm-vue3-print/core` | 模板表达式引擎、同构渲染管线、框架无关的设计器内核 | 浏览器 / Node，纯 TypeScript |
| `@worm-vue3-print/canvas` | Vue 3 可视化设计器（`PrintDesigner`）与浏览器打印预览（`PrintHtmlPreview`） | Vue 3 浏览器 |

- `core` 通过子路径导出：主入口为引擎与渲染能力，`/designer` 为设计器内核，`/browser` 为浏览器侧渲染适配器，`/client` 为静默打印浏览器端 SDK。
- canvas 包不依赖任何 UI 组件库（无 Element Plus），模板保存、字段查询、截图、图片上传等宿主能力通过 props / 事件 / 适配器注入。

## 二、安装

设计器需要 core 与 canvas 两个包：

```bash
npm install @worm-vue3-print/core @worm-vue3-print/canvas
```

需要静默打印时无需另装 SDK，从 `@worm-vue3-print/core/client` 导入即可（另需在工位电脑运行桌面打印客户端，见《静默打印》）。

## 三、引入设计器

canvas 提供**具名导出**，不是 Vue 插件，不需要 `app.use()`。
其内部控件基于原生样式，需全局引入一次样式文件：

```ts
import { PrintDesigner } from '@worm-vue3-print/canvas'
import type { PrintBusinessField, TemplateData } from '@worm-vue3-print/canvas'
import '@worm-vue3-print/canvas/native-controls.css'
```

```vue
<template>
  <PrintDesigner
    :initial-template="templateData"
    :fields="fields"
    :is-edit="true"
    @preview="onPreview"
    @save="onSave"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { PrintDesigner, createDefaultTemplate } from '@worm-vue3-print/canvas'
import type { PrintBusinessField, TemplateData } from '@worm-vue3-print/canvas'

const templateData = ref<TemplateData>(createDefaultTemplate())
const fields = ref<PrintBusinessField[]>([
  // fieldKey 为打印数据中的完整路径；分组不依赖 fieldType：
  // 无点且作为其它字段前缀的记录自动成为分组容器（如 supplier）；
  // fieldType 为 'list' 的容器（如 goods）作为表格「列表数据源」选项
  { fieldKey: 'supplier', fieldLabel: '供应商', fieldType: 'string', sortOrder: 1 },
  { fieldKey: 'supplier.name', fieldLabel: '供应商名称', fieldType: 'text', sortOrder: 2 },
  { fieldKey: 'amount', fieldLabel: '金额', fieldType: 'number', sortOrder: 3 },
])

function onSave(json: string) {
  // json 为模板 JSON 字符串，由宿主持久化
  console.log('保存模板', JSON.parse(json))
}

function onPreview() {
  // 预览的接线见下一节
}
</script>
```

> 模板 JSON 只含版面数据（纸张、边距、元素等），模板名称、业务类型等元信息由宿主在自己的业务流程中管理。

## 四、浏览器端免保存预览

点击设计器工具栏「预览」时，通过组件 ref 取出当前画布 JSON，交给 `PrintHtmlPreview`。
预览完全在浏览器内完成（隐藏 iframe 两遍渲染 + 分页），不需要服务端：

```vue
<button type="button" @click="onPreview">打印预览</button>

<div v-if="previewVisible" class="preview-mask">
  <div class="preview-panel">
    <button type="button" @click="htmlPreviewRef?.print()">打印</button>
    <PrintHtmlPreview
      ref="htmlPreviewRef"
      :template-json="previewJson"
      :print-data="printData"
      :base-url="baseUrl"
      @rendered="(n) => previewPages = n"
    />
  </div>
</div>

<script setup lang="ts">
import { ref } from 'vue'
import { PrintDesigner, PrintHtmlPreview } from '@worm-vue3-print/canvas'

const designerRef = ref<InstanceType<typeof PrintDesigner> | null>(null)
const htmlPreviewRef = ref<InstanceType<typeof PrintHtmlPreview> | null>(null)
const previewVisible = ref(false)
const previewJson = ref<Record<string, any> | null>(null)
const previewPages = ref(0)

// 业务打印数据（字段路径与 fields 中的 fieldKey 对应）
const printData = ref({ supplier: { name: 'ACME 公司' }, amount: 1234.5 })
// 模板中 /docfiles/... 等相对路径图片的拼接基址；无相对图片可不传
const baseUrl = ''

function onPreview() {
  const json = designerRef.value?.getTemplateJson?.()
  if (!json) return
  previewJson.value = json as unknown as Record<string, any>
  previewVisible.value = true
}
</script>
```

`PrintHtmlPreview` 内部调用 `@worm-vue3-print/core/browser` 的 `renderHtmlPages`，
暴露 `print()`（唤起浏览器原生打印，可选「另存为 PDF」）与 `rerender()`。
浏览器预览组件本身**不产出 PDF 文件**；需要程序化 PDF 请走 render 微服务，见《渲染管线》。

## 五、在 monorepo 内运行 demo

仓库自带完整集成示例（设计器 + 浏览器预览 + 服务端 PDF + 静默打印）：

```bash
npm install
npm run build            # workspace 之间存在软链依赖，先整体构建
npm run dev:demo         # demo 默认监听 http://localhost:9303（在仓库根执行）
```

demo 中的「服务端 PDF」通过同源路径 `/render-api/*` 调用 render 微服务：
本地联调时由 Vite dev 代理转发到 `http://localhost:3001`（可用 `VITE_RENDER_TARGET` 覆盖），
并在代理层注入 `X-Render-Key`（默认 `dev-render-key`，可用 `VITE_RENDER_API_KEY` 覆盖）。
启动 render 微服务：

```bash
npm run dev:render   # 或参见 services/print-render/README.md 的 Docker 方式
```
