# 打印设计工作台 · 布局线框图与说明

> 本文档描述 `@worm-vue3-print/canvas` 打印设计工作台的整体布局，作为后续调整工作台外观与结构的参照。
> 核心组件：`src/components/PrintDesigner.vue`（工作台容器），各区域划分详见下文。

## 各区域细分说明

### 一、顶部工具栏（DesignerToolbar.vue）

| 分区 | 内容 | 悬浮提示 |
|---|---|---|
| **标题区** | Logo 图标 + 「编辑模板/新建模板」主标题 + 「打印模板设计器」副标题 | — |
| **编辑区** | 撤销 ↶、重做 ↷ | 撤销 / 重做 |
| **对齐区**（多选时显示） | 左对齐、右对齐、顶对齐、底对齐、水平居中、垂直居中、水平分布、垂直分布 | title 提示 |
| **组合区** | 组合 / 取消组合（多选时显示） | 组合 / 取消组合 |
| **层级区**（有选中时显示） | 置顶 ⤒、上移 ↑、下移 ↓、置底 ⤓ | 置顶 / 上移一层 / 下移一层 / 置底 |
| **视图区** | 标尺、网格、虚框、吸附 四个开关 + 适应窗口 ⤢ + 缩小−、缩放百分比、放大＋ | 显示/隐藏标尺、显示/隐藏网格背景、显示/隐藏无边框表格的虚拟虚线、开启/关闭元素吸附到网格、适应窗口、缩小、放大 |
| **操作区** | 帮助？、首页专属、叠层对比、加载默认布局、**预览**、**保存**（蓝色主按钮） | — |

- 各区按钮悬浮提示统一使用 `data-tip` 自定义气泡（深色圆角），禁用态按钮不弹提示。
- 注意：工具栏对外 `z-index: 100`，须高于画布顶部标尺 `ruler-overlay`（z-index: 60），否则提示气泡会被标尺遮挡。

### 二、左栏 · 素材台（LeftPanel.vue）

| 分区 | 内容 |
|---|---|
| **头部** | 「素材台」标题 + 收起按钮（折叠后变 36px 竖排图标条） |
| **页签栏** | 元素 / 字段 / 图层 |
| **元素页签** | 「拖拽元素到画布」——文本、条形码、二维码、图片、表格、长文、横线、竖线、矩形、椭圆、HTML（11 种，均可拖拽） |
| **字段页签** | 业务字段——搜索框 + 分组字段树（FieldTreePanel.vue，可按字段分组折叠，可拖拽生成绑定） |
| **图层页签** | 图层列表（图标 + 名称 + 页眉/页脚标记 + z 序）+ 置顶/上移/下移/置底按钮（LayerPanel.vue） |

### 三、中央画布区（CanvasArea.vue + CanvasPaper.vue）

| 分区 | 内容 |
|---|---|
| **标尺层** | 视口固定水平标尺 + 垂直标尺 + 左上角逐块（Ruler.vue，不随纸张滚动，刻度随滚动/缩放同步；可从标尺拖出参考线） |
| **纸张本体** | 白纸，含可开关的 **网格背景**、**水印渲染层**（位于所有元素之下） |
| **页眉区域** | 纸张顶部窄区，显示「页眉」标签，底边有可拖拽的高度调节手柄（拖拽时气泡显示实时高度 mm） |
| **内容区域** | 纸张主体区，顶部含「首页叠加」占位条（仅设计态显示） |
| **页脚区域** | 纸张底部窄区，显示「页脚」标签，顶边有可拖拽的高度调节手柄 |
| **叠层对比层** | 开启「叠层对比」后半透明覆盖纸张，与设计稿截图对比 |
| **参考线/框选** | 标尺可拖出参考线；按住鼠标可框选多元素（drag 方向决定交集/包含命中） |
| **右键菜单** | 选中元素：复制/剪切/粘贴/删除/置顶/上移/下移/置底/编组/取消编组；空白处：粘贴/全选/取消选择 |

### 四（无）

### 五、右栏 · 属性台（PropertyPanel.vue）

| 分区 | 内容 |
|---|---|
| **头部** | 「属性台」标题 + 收起按钮（折叠后变 36px 竖排图标条） |
| **页签栏** | 元素属性 / 页面属性 |
| **元素属性页签** | 属性搜索框 + 位置尺寸组 + 外观组 + 内容/绑定组（含图片上传）+ 表格设置组（表格元素）+ 边框背景组 + 分页配置组 + 高级组（含删除元素按钮）；无选中时显示「请在画布中选择一个元素」 |
| **页面属性页签** | 纸张设置（纸张尺寸下拉 / 自定义宽高 / 方向 / 页面背景色）+ 页边距（上/下/左/右）+ 三区高度（页眉 / 页脚 / 首页叠加高度） |

### 六、底部状态栏（StatusBar.vue）

`鼠标坐标(x,y mm) ｜ 缩放 % ｜ 元素数量(选中数) ｜ 未保存/已保存 ● ｜ 纸张尺寸 + 横/纵向`

### 七、浮层（覆盖在工作台之上）

| 组件 | 触发方式 | 内容 |
|---|---|---|
| **表达式编辑器**（ExpressionEditor.vue） | 双击文本/条码/二维码/图片元素或表格单元格 | 表达式输入框 + 字段选择 |
| **帮助文档模态框**（HelpModal.vue） | 点击工具栏「帮助」 | 帮助文档内容 |
