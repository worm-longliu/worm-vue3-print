## 抖音竖屏视频：MCP 原理讲解（项目对外传播物料）

产出物在 `/tmp/worm-print-video/`：
- `worm-vue3-print-mcp-vertical.mp4`（9:16 主版 1080×1920 / 27.77s / H.264 High / yuv420p / 3.5MB）
- `worm-vue3-print-mcp-3x4.mp4`（3:4 版 1080×1440，由主版中央裁切）
- `cover.jpg`（首帧封面）、`safezone-guide.png`（安全区示意）

### 抖音安全区几何（沿用这套坐标）

- 视频画布 1080×1920；核心内容卡固定 **x 80..980、y 360..1560**，即 900×1200 = **精确 3:4**，水平偏左以避开右侧操作栏。
- 顶部 360px 让给「返回/作者信息」，底部 360px 让给「文案/进度条/展开」，右侧 100px 让给「头像·点赞·评论·转发」。
- 结论：**所有文字（含字幕）必须画在卡片内部**，绝不放卡片外，否则会被抖音 UI 压住。

### 生成管线（本机可复现）

1. 手写 `scenes.html`：6 个 `.scene`（每个 1080×1920），CSS 定位即安全区坐标，不用手算 margin。
2. Playwright（Chromium 已在 `~/Library/Caches/ms-playwright/chromium-1243`）按 `.scene` 元素逐个截图，`deviceScaleFactor: 2` → 2160×3840 PNG。
3. `ffmpeg-static`（`npm install --no-save ffmpeg-static`，不改 package.json/lock）合成：每图 `zoompan` 微推近 + `xfade=transition=fadeblack:duration=0.45` 章节切换。
   - 文字类场景**不要用普通 `fade` 交叉淡入**：两幕文字会叠在一起显脏，必须 fadeblack 淡出到黑。
4. 3:4 版用 `crop=1080:1440:0:240` 从主版裁。

### 坑

- `npm install --no-save` 后 ffmpeg 覆盖已有文件会**卡在交互式确认**（`Overwrite? [y/N]`）——命令里必须加 `-y`，否则后台任务假死。
- Bash 工具默认超时 120s，ffmpeg 合成要放后台跑并写日志文件。

### 视频内容口径（已与源码核对，勿改错）

- MCP 桌面端实际可用 8 个工具：会话类 `print_list_open_templates` / `print_get_open_template` / `print_apply_open_template`；计算类 `print_element_kinds` / `print_validate_template` / `print_check_expression` / `print_inspect_layout` / `print_draft_template`。
- `print_render_preview` 桌面端被排除（`desktop-tools.ts` 的 `DESKTOP_BLOCKED_TOOL_NAMES`），需要渲染服务 + API Key，**不要在视频里说成桌面端能力**。
- 桌面端拒绝 `templatePath`，只能传 `templateJson`；`apply` 是整份替换 + `baseRevision`（一次撤销可恢复）。
- 架构链路：AI Agent → MCP Server(stdio) → 打印桌面客户端(Electron，桥接浏览器画布) → print-core 引擎 + print-canvas 设计器；设计器每次改动本质是一份 template JSON。
