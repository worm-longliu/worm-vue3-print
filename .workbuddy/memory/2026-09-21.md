## 新增「综合实力模板」comprehensive-showcase

需求：A4 横向、多级表头、表格同表混排条形码 + 二维码 + 图片，图片放 demo，用 localhost:9303 绝对地址。

关键事实（渲染管线，可复用）：
- 表格单元格 `cellType: 'image'` 的图片 URL 走 **formatter**（不是 src）；条码/二维码码值也走 formatter。简写里即 `{ "type":"image", "text":"{image}" }`。
- 多级表头用两行 header：第一行分组单元格 colspan，第二行补细列；不跨组的列（序号/单位）在第一行用 rowspan=2。占位格 build_template.py 自动补。
- 元素高度口径沿用既有模板约定：按「单行 data 骨架」算高度（本模板 8+8+28+9=53mm），数据迭代后设计器/渲染回写，可避免 validate 的行高 WARN。
- 本机 9303 已有 demo dev server 在跑，public 新增文件 vite 即时可读；另起会落到 9304。

产出文件：
- demo：`demo/src/template-comprehensive-showcase.json`、`demo/src/samples/comprehensive-showcase.ts`（已注册到 samples/index.ts）、`demo/public/images/goods-1~4.png`。
- skill：`skills/print-template-json/assets/templates/comprehensive-showcase.{template,data}.json`、manifest 第 8 条、SKILL.md 改「8 份」。
