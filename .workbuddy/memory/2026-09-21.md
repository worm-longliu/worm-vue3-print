## EdgeOne 云端构建失败修复（b202c6d）

- 报错：`Rollup failed to resolve import "jsbarcode" from packages/print-core/src/...`。根因：vite alias 直接编译 packages 源码，裸模块按 Node 解析规则只向上到仓库根 `node_modules`；云端只执行 `npm ci --prefix demo`（依赖在 demo/node_modules），根上没有 node_modules。本地能构建是因为根有 workspace 安装。
- 修法：edgeone.json installCommand 改 `npm ci --prefix demo && ln -sfn demo/node_modules node_modules`，在仓库根建指向 demo/node_modules 的相对软链（-sfn 幂等，可重复部署），packages 源码即命中同一份依赖。
- 已在本地把根与 demo 的 node_modules 全移走，按云端 install+build 流程实测通过后还原。
- Node 22.11.0 是 EdgeOne 预装最高版本（另有 20.18.0），低于 Vite 7 要求的 20.19+/22.12+，但那只是警告不阻断，保持 22.11.0。
