- 单元格条码属性（与元素级不同）：`showBarcodeText`（源码按 `!== false` 判定，未设即显示）、`barFontSize`（条码文本字号，是**相对条高的模块值**，默认 10、范围 5~24，**不是 pt**）。元素级条码才用 `fontSize` / `hideTitle`。这两个键在 `skills/print-template-json/references/template-schema.md` 有记载，改模板前可先查。
- MCP 写回流程：`print_list_open_templates` → `print_get_open_template`（拿 revision 与完整 templateJson）→ 改 JSON → `print_apply_open_template` 带 `baseRevision` **整份替换**（一次撤销可恢复，旧 revision 会被 REVISION_CONFLICT 拒绝）→ 再 `get` 复核。apply 自带契约校验，会规范化属性顺序；`fields` / `printData` 属页面侧状态，不在 templateJson 里，替换不会丢。
- 页面必须保持打开，关闭即会话失效；快照无缓存。

## 生成 A5 中医处方笺模板（MCP 写回画布）

- 用户换了空白 A5 纵向画布（header 15 / footer 13 / 边距 8，版心 132×166mm），字段与 printData 是一份中医处方（hospital/department/patient/sex/age/prescNo/diagnosis/drugs[{name,spec}]/note/doctor/amount）。按《处方管理办法》前记—Rp—后记三段式设计并写回（revision `57312b77`），契约校验 issues/warnings 全空。
- 版面：页眉机构名+「中医处方笺」+日期+红色分隔线；前记用纯 header 行表格做栅格（5 列 4 行，右上角 colspan 条码 `rowspan:4` 绑 `{prescNo}`）；正文 Rp + 药品明细表（`dataSource: drugs`，3 列，行内 `{name}`/`{spec}`，header `repeatOnPage`）；「重要医嘱」浅红框用 text 标题条 + longText 绑 `{note}`；后记费用 `¥{MONEY(amount)}`、医师、五级签名栏；页脚法规提示 + 打印时间 + 页码。
- 关键约定：**表格 data 行会按数组展开，下方元素由引擎「随表格展开下移」**（见 `skills/print-template-json/references/layout-recipes.md` 第 27 行，综合示例模板 el4 的 top 就是按表格**声明高度**排的）。所以模板里下方元素的 top 要紧跟表格声明高度之后，不要按展开后高度写死。
- 单元格 `borders` 四边都是可选（`TableCellBorders`），只写 `bottom` 即可做「下划线式处方笺」，比给每格写四边框省大量 JSON。
- 设计器会把表格 `height` 回写为实际渲染尺寸（本次 28→28.31、13→14.29），属正常；排版时给后续元素留 1.5mm 以上间隔。
- 当前 MCP **没有** `print_render_preview` 工具，`print_inspect_layout` 明确不判表格真实行高/长文本换行/真实页数。动态明细展开后的真实落位只能让用户在预览里确认；若末尾被挤到第二页，把 data 行高调小（6→5）或压缩下方区块间距即可。

## 药味明细改用流式列表（revision `a8b18863`）

- 用户要求药物信息不用表格、改 `flowList`。已替换：删 `drugTable`，加 `drugFlow`（left 0 / top 38 / 132×44mm），前记信息栅格表保留（它不是药物信息）。
- flowList 契约（源码实证：`packages/print-core/src/render/__tests__/flow-list-render.spec.ts`、`html-generator.ts:500-521`）：
  - `formatter` 是**一条完整表达式**，单元模板写行内字段 `{name}　{spec}` + `dataSource: "drugs"` 即可逐项求值；也可把列表路径写进表达式 `{drugs.name} {drugs.spec}` 不配 dataSource。分隔符用**全角空格**（半角多空格会被 HTML 折叠）。
  - `flowColumns` 必填（缺省 4）、`flowRowHeight` 最小行高语义（缺省 8）、`flowGapX`（缺省 4）、`fontSize` 必须给（缺省 12 偏大）。
  - 出纸是 CSS grid `repeat(N,minmax(0,1fr))` + `overflow:hidden`，**框高写死、一框一页不续页**，超出按 `textFit`（缺省 clip）裁掉；**不会把下方元素下移**，与表格的「随展开下移」正好相反。
  - `flowAutoSpan` 让长单元跨列，**只在出纸生效**；画布 `FlowListElement.vue` 本身也按 `flowColumns` 分列，所以关掉 autoSpan 时画布与出纸一致。
- 布局结论：换 flowList 后把下方区块按**固定框底**（38+44=82mm）重排（医嘱 85 / 91，费用 108，签名 116 / 122，提示 130），整页最底 135mm < 版心 166mm，布局完全静态可控，不再有表格展开是否溢出的不确定。
