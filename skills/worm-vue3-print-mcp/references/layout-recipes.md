# 常见打印场景版式配方

所有数值单位 mm，字号 pt。坐标相对内容区左上角。先定纸 → 算版心 → 排元素 → 跑校验（见 SKILL.md）。

## 通用排版流程

1. **定纸**：按场景选 `paperSize`（纸张表见 template-schema.md §3）
2. **算版心**：`内容宽 = 纸宽 − 左 − 右`，`内容高 = 纸高 − 上 − 下 − 页眉高 − 页脚高`
3. **算安全线**：固定纸的内容底边必须离版心底边 ≥ 2mm，否则溢出到第二页
4. **排元素**：从上到下切横条，每条一个元素；同一行用两个元素左右并排
5. **校验**：`python3 scripts/validate_template.py out.json`，修到 0 ERROR

## 配方一：单据（A5 / A4 / 针式纸）

| 区块 | 建议 |
|---|---|
| 抬头 | 公司名 `fontSize 14~16`、`weight bold`、`align center`，高 7~8 |
| 单据标题 | 与抬头同行或下一行，居中，高 6 |
| 元信息 | 用**纯 header 行的表格**做栅格（如 4 列 × 2 行），或直接放文本元素；左对齐 |
| 分隔线 | `hline`，height 0.2，`borderWidth 0.4`，色 `#333` |
| 明细表 | `dataSource` 指向数组，列宽和 = 元素宽；header 行 `repeatOnPage: true` |
| 每页小计 | `subtotal` 行，`{MONEY(SUM(amount))}`（只聚合当前页） |
| 合计 | `summary` 行；金额大写另起文本 `{UPPER(order.total)}` |
| 签名栏 | 底部 2~3 个文本元素左右并排：「制单人 / 仓管员 / 收货人签字」 |
| 页码 | `{pageIndex} / {totalPages}`，放页脚最稳 |

明细行数多会跨页：`data` 行按可用高度自动分页，`header` 行重复、下方元素随表格展开下移。

## 配方二：标签（40×30 / 60×40 / 80×60）

纵向切条，**最后一条的底边留 2mm**：

| 60×40（边距 2 → 版心 56×36，安全线 34） | 高 | 字号 |
|---|---|---|
| 门店名 | 4.2 | 8 |
| 品名（bold） | 5.4 | 11 |
| 单价说明 | 4 | 8 |
| 净重（左半）+ 金额（右半，红色 `#c8211e`） | 5 | 9 / 12 |
| 分隔线 | 0.2 | — |
| 条码（带 `printerDpi`） | 8 | — |
| 包装/保质期 | 3.2 | 6.5 |
| 门店/追溯码 | 3.2 | 6.5 |

40×30 更紧：品名 9pt、价格 16pt、条码高度 ≥ 5.5、底部 6pt 一行足够。
条码的 `barWidth` 用 2，`printerDpi` 用 203（热敏）或 300。

## 配方三：小票（80mm 连续纸）

- 边距左右各 3 → 内容宽 74；**连续纸不检查安全余量**，高度按内容推导
- 店头（11pt 居中）→ 地址/热线（7pt）→ 单号/收银员/时间（8pt）→ `hline`
- 明细表：列宽 `[38, 12, 12, 12]`，header 6 / data 6 / summary 6
- 合计行、收款找零、二维码（28×28 居中）、页脚「欢迎再次光临」（8pt 居中）
- 最小字号 6.5pt（203dpi 热敏再小就糊）

## 配方四：快递面单（100×150 自定义纸）

`paper: {"size":"CUSTOM","width":100,"height":150}`，边距 3。
三段式：寄件人（左上）→ 收件人（中部大字号 12~14pt，电话脱敏）→ 条码 + 签收栏。
右下角放打印时间与客服热线。

## 配方五：拼版标签（A4 上排多枚）

- 标签模板自己的 `margins` 建议留 1~2mm（标签内部边距）
- `tiling.sheetMargin` 是 A4 的留白，默认 10；`gapX/gapY` 2
- A4（210×297，留白 10 → 可用 190×277）能放：
  - 40×30 标签：4 列 × 9 行 = 36 枚
  - 60×40 标签：3 列 × 6 行 = 18 枚
- 列数宁小勿大，先算 `floor((可用宽 + gapX) / (标签宽 + gapX))`

## 避坑清单（每条都对应真实故障）

1. **2mm 安全余量**：固定纸内容底边贴版心底边 → 被判到第二页；拼版模板直接拒绝出纸
2. **条码不清晰**：热敏必给 `printerDpi: 203`，否则模块宽非整数打印点，条宽忽宽忽窄、边缘发灰
3. **表格占位格**：`colspan`/`rowspan` 覆盖的格必须补 `{ "id","merged":true }`，否则整行错位
4. **列宽/行高和**：应分别等于元素 width/height；不等时设计器会按实际渲染尺寸回写，可能顶开版心
5. **拼版 1 页约束**：每份标签只能 1 页，内容溢出即拒绝
6. **连续纸拼版**：不支持，别开 `tiling`
7. **表达式**：`{}` 必须闭合；未知函数名不会渲染出值
8. **元素越界**：`left + width` 超内容宽会被裁；拼版下还会连累相邻格
9. **页眉页脚**：高度计入版心占用，设了高度就要从内容高里扣掉
10. **导入门槛**：单页要有 `paperSize` + `margins` + `elements`，多页是 `{pages:[...]}`
